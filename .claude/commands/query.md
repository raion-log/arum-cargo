당신은 지금 이 저장소의 wiki 관리자입니다.

## 작업 순서 (엄격히 준수)

1. **반드시 먼저** `wiki/schema.md` 를 읽어 최신 워크플로우·제약을 로드하세요.
2. `$ARGUMENTS` 가 비어 있으면 사용자에게 질문을 요청하고 종료하세요.

## Query 파이프라인 (schema.md §6)

### Step 1. 관련 페이지 식별
- `wiki/index.md` 를 읽어 질문과 관련된 entities/concepts/sources 를 목록화
- 관련도 높은 페이지 최대 10개 선정

### Step 2. 페이지 읽기 및 확장
- 선정된 페이지를 읽고, 해당 페이지의 wikilink 를 통해 관련 페이지로 추가 확장
- 서로 연결된 페이지를 따라가며 맥락을 넓힘

### Step 3. 인용 기반 답변
- **모든 주장은 `[[wiki/페이지]]` 또는 `source_url` 로 근거 표기**
- 불확실한 정보는 "확인 필요" 명시, 추측 금지
- 관련 source 가 없으면 "wiki 에 아직 해당 정보 없음" 명시

### Step 4. 가치 있는 종합은 페이지화 (선택)
- 사용자의 질문에서 새로운 비교·분석·인사이트가 도출되면:
  - `wiki/concepts/` 또는 `wiki/entities/` 에 새 페이지 생성 제안
  - 사용자 동의 시 즉시 생성

## 마무리

1. `wiki/log.md` 끝에 append:
   ```
   ## [YYYY-MM-DD] query | <질문 요지 1줄>
   - 참조 페이지: N건
   - 새 페이지 생성: N건 (0이면 생략)
   ```
2. 답변 하단에 **참조한 wiki 페이지 목록** 첨부

## 절대 금지

- wiki 에 없는 정보를 있는 것처럼 답변
- `raw/` 파일 수정
- 사용자 승인 없이 기존 entity/concept 페이지 내용 대폭 수정
