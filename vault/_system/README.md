# arum-aviation-hub Vault

> *arum-aviation-hub 프로젝트의 지식·작업·결정·진화 기록*용 Obsidian vault.

## 매일 사용 흐름

1. **세션 시작**: `../memory/_current.md` + `../memory/_pending.md` 점검
2. **작업 진행**: `../daily/YYMMDD.md`에 한 줄 요약 + 작업 항목 누적
3. **자료 적재**: `_inbox/` → `../raw/`로 (출처 표기)
4. **압축**: 반복 개념 → `../topics/`
5. **결정 기록**: 운영 결정·트레이드오프 → `../decisions/`
6. **세션 종료**: `../memory/_pending.md` 갱신 + `../daily/YYMMDD.md` 한 줄 요약
7. **운영 룰**: `../SCHEMA.md` 참조
